## 🚨 First Time Issues?

### Can't start?
```bash
rm -rf node_modules
npm cache clean --force
npm install
npm start
```

### Port 4200 taken?
```bash
ng serve --port 4300
```

### Images missing?
Run the setup script again:
```bash
./setup.sh    # macOS/Linux
setup.bat     # Windows
```
