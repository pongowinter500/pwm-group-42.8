================================================================================
  TROUBLESHOOTING QUICK FIXES
================================================================================

Can't start the app?
  → rm -rf node_modules
  → npm cache clean --force
  → npm install
  → npm start

Port 4200 already in use?
  → ng serve --port 4300

Images not showing?
  → Run setup script again:
    Windows: setup.bat
    macOS/Linux: ./setup.sh

Build errors?
  → Delete node_modules folder
  → npm cache clean --force
  → npm install
  → npm start

For more help: See INSTALLATION.md Troubleshooting section
