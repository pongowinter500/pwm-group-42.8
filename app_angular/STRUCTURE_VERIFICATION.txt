## 🔧 Installation Verification

Before running the application, verify the following:

### Step 1: Verify Directory Structure
```bash
cd app_angular
tree src/app   # Should show all components and pages
```

### Step 2: Check Node.js Installation
```bash
node --version  # Should be v18 or higher
npm --version   # Should be 8 or higher
```

### Step 3: Install Dependencies
```bash
npm install
```

### Step 4: Set Up Data & Images
```bash
# On macOS/Linux
./setup.sh

# On Windows
setup.bat
```

Or manually:
```bash
mkdir -p public/data public/assets/images
cp ../data/content.json public/data/
cp -r ../images/* public/assets/images/
```

### Step 5: Start Development Server
```bash
npm start
# Opens http://localhost:4200
```

### Step 6: Verify All Pages Load

Navigate to these routes and verify they load correctly:

- ✅ `http://localhost:4200/` - Home page with course slider
- ✅ `http://localhost:4200/about` - About page with mission statement
- ✅ `http://localhost:4200/business` - Business page with features
- ✅ `http://localhost:4200/login` - Login page with form
- ✅ `http://localhost:4200/course/1` - Course detail page

### Step 7: Test Responsive Design

Using Chrome DevTools (F12), test at these breakpoints:

- ✅ Mobile: 375px × 667px
- ✅ Tablet: 768px × 1024px
- ✅ Desktop: 1920px × 1080px

### Step 8: Verify CSS Styling

Compare with original HTML version and verify:

- ✅ Header styling and navigation
- ✅ Footer layout and links
- ✅ Course card styling and hover effects
- ✅ Page-specific styling (About, Business, Login)
- ✅ Typography and spacing
